# Apply Skill

Implement the assigned tasks and keep TDD evidence. When blocked, ask via `present blocking gate questions as a structured numbered markdown list in chat (e.g. "1) Option A  2) Option B"), then STOP and wait for the user's reply — do not invoke any tool to ask — and persist the accepted decision in `state.yaml``.
