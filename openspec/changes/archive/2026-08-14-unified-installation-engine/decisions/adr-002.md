# ADR-002: Fail-Closed Configuration Merging

- Status: proposed
- Change: unified-installation-engine
- Date: 2026-08-14

## Context
When merging OSpec entries into existing user configuration files (`opencode.json`, `mcp-config.json`, `settings.json`, `hooks.json`), previous installers fell back to an empty object `{}` upon JSON parse errors, silently overwriting and destroying the user's config file.

## Decision
Enforce a strict fail-closed contract across all target installers: if an existing target configuration file exists but cannot be parsed cleanly, abort installation immediately with an informative error and perform zero writes.

## Alternatives
- Fall back to `{}` on error: Rejected because it causes irreversible data loss.
- Skip config step on error: Rejected because it leaves runtime in a partially broken state.

## Consequences
User configuration files are guaranteed safe against destructive overwrites; malformed configs fail loudly and predictably.
