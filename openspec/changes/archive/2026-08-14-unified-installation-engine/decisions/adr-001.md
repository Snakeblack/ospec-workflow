# ADR-001: Ownership Manifest for Target Convergence

- Status: proposed
- Change: unified-installation-engine
- Date: 2026-08-14

## Context
Global installation commands (`setup:*`) copy assets into host/user homes. Over time, deleted or renamed canonical agents and scripts remain as orphaned "ghost" files in user homes because installers only copy additively.

## Decision
Introduce a standard `.ospec-workflow-install.json` in target root directories recording all files owned by OSpec Workflow. On subsequent runs, compute `stale = previous_owned - current_owned` and delete stale files while leaving user-created files intact.

## Alternatives
- Recursive deletion of whole directories: Rejected because it destroys custom user agents/skills.
- No manifest tracking: Rejected because installers cannot distinguish OSpec files from user files.

## Consequences
Setup scripts achieve true convergence and idempotency without risk of deleting user-owned assets.
