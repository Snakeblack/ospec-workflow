# ADR-003: Antigravity First-Class Target Profile

- Status: proposed
- Change: unified-installation-engine
- Date: 2026-08-14

## Context
Antigravity was supported solely through a bespoke `scripts/sync-antigravity.js` script that hardcoded personal paths, bypassed the compiler pipeline, copied unneeded test/generator files, and did not validate generated assets.

## Decision
Promote Antigravity to a standard target profile (`scripts/lib/target-profiles/antigravity.js`) and validator (`scripts/configure/validate-antigravity.js`) registered in `scripts/configure/cli.js`. Replace `sync-antigravity.js` with `scripts/configure/install-antigravity.js`.

## Alternatives
- Retain `sync-antigravity.js`: Rejected because it creates architectural divergence, lacks validation, and risks regressions.

## Consequences
Antigravity gains identical validation, runtime closure, model mapping, and transactional installation safety as all other targets.
