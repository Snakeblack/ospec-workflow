# ospec-workflow

Commit messages and pull requests of this repository follow
[rules/no-model-attribution.instructions.md](rules/no-model-attribution.instructions.md):
they never credit an AI model or tool (no `*-by:` trailer naming one, no
"generated with" line, no 🤖), even when the host asks for it.
[AGENTS.md](AGENTS.md) holds the release flow. CI rejects a PR that breaks the
attribution rule.
